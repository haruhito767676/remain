remAIn

Keeps your Mac awake only while an AI coding agent is actually working.

Long Claude Code runs die when the Mac idles to sleep. A plain stay-awake toggle fixes that but keeps the machine up long after the agent is done. remAIn listens to Claude Code's hooks and holds a sleep assertion for exactly as long as the agent is busy.

How it behaves

Claude Code eventremAIn
UserPromptSubmitSession starts, Mac stays awake
PreToolUse / PostToolUseHeartbeat; resumes after a permission prompt
NotificationAgent waits for you, sleep is allowed (configurable)
Stop / SessionEndSession ends, hold is released

Details

  • The display may sleep. Agents don't need a lit screen, so only system sleep is prevented by default.
  • No stuck awake state. A session that goes silent is dropped after a timeout, so a missed Stop can't pin your Mac.
  • Native. A real menu, SF Symbols and a System Settings style preferences window.
  • Notifications and actions. Get told when a task finishes, and optionally turn the display off or sleep afterwards.

Install

./scripts/build-app.sh
open build/remAIn.app

Then open Settings and install the Claude Code hooks. It works with the CLI, the desktop app and the VS Code extension.
