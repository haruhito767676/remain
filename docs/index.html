AI works on its own. Your Mac doesn’t know.

Three ways a Mac gets it wrong.

Sleep cuts the run

The Mac falls asleep in the middle of a task, and a long run stops halfway.

caffeinate doesn’t know when to stop

Wrapping a command keeps the Mac awake, but you start and end it by hand. Forget it, and the Mac stays up all night until the battery gives out.

Not every agent is a command

IDEs, desktop apps and background runs can’t be wrapped in one.

Awake only while they work.

remAIn follows the agent itself, not a timer, and lets go the moment it is done.

It follows the agent

Each agent reports when it starts, works, waits for you and finishes, and remAIn holds the Mac awake for exactly that long.

The menu bar icon tells you what is going on: a sparkle while an agent works, a moon when the Mac may sleep.

Any agent. All at once.

Antigravity, Claude Code, Codex, or any command you wrap with remain run. Several at once are fine, and the Mac stays awake until the last one is done.

Close the lid. It keeps going.

Off by default. When you turn it on, the work carries on with the lid closed, and the Mac sleeps when it is over.

It stops on its own for heat, low battery or a time limit, and a watchdog restores normal sleep even if remAIn itself crashes.

Stopped halfway? It notices.

If an agent is interrupted, crashes, or its window is closed, remAIn lets the Mac sleep again. When a long run stops unexpectedly, it tells you.

Questions

Does it connect to the internet?

No. The app, the remain command and the hooks only talk to each other over a Unix socket that your user alone can open.

What if an agent crashes, or I close its window?

remAIn notices that the process is gone, or has been quiet for too long, and lets the Mac sleep again. If the run lasted long enough, it tells you the agent stopped unexpectedly. If you stop an agent yourself with Esc, nothing is shown.

How is this different from caffeinate?

caffeinate holds for as long as the command it wraps, and you have to remember to start it. remAIn follows the agent itself, including IDEs and desktop apps, and lets go on its own.

Can it drain the battery in a bag?

It lets the Mac sleep when the battery is low, when it is on battery power, in Low Power Mode, or when it is hot. Lid-closed mode is off by default and has a time limit.

Why does macOS warn me about the app?

remAIn is not signed by Apple. You only need to allow it once, in System Settings → Privacy & Security.
