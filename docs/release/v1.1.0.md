## remAIn 1.1.0

**A heads-up when an agent stops unexpectedly.**

### What's new
- **Unexpected stops are reported.** If an agent crashes, or you close its window, while it was working, remAIn lets your Mac sleep again and sends a notification: "An agent stopped unexpectedly" (with the project name and "Keep-awake has ended."). The same goes for a run that goes silent past the safety timeout. Short runs stay quiet (the same 30-second minimum as the finish notification), and so does stopping an agent yourself with Esc. It follows the *Notify when a task finishes* switch in Settings.
- **A calmer welcome window.** *Open remAIn at login* is now a switch right in the window, the text is shorter, and the Settings and welcome windows no longer open dimmed.
- **Fixes.** The notification status refreshes when you come back from System Settings, and the zero of the Activity chart is labelled.

### Updating
Quit remAIn, replace it in Applications with the new version and open it. Your settings and history are kept. remAIn is still **not signed** by Apple, so macOS may ask you to allow it again (*System Settings → Privacy & Security → Open Anyway*).

Everything else is as in 1.0.0. Details: [README](https://github.com/haruhito767676/remain#readme)

## remAIn 1.1.0（日本語）

**エージェントが予期せず止まったときに、お知らせします。**

### 新しくなったこと
- **予期せぬ停止をお知らせ。** 作業中のエージェントが落ちたり、ウィンドウを閉じられたりしたときに、remAInがMacをスリープできる状態に戻し、「エージェントが予期せず止まりました」(プロジェクト名と「スリープ防止を終了しました。」つき)と通知します。長く無反応で、安全のためのタイムアウトに達した場合も、同じです。短い作業(完了通知と同じ30秒未満)と、自分でEscを押して止めたときは、通知しません。設定の「作業が完了したら通知する」に従います。
- **ようこそ画面を、すっきり。** 「ログイン時にremAInを開く」が、ウィンドウの中のスイッチになり、文章も短くなりました。設定とようこそのウィンドウが、薄暗い状態で開くこともなくなりました。
- **修正。** システム設定から戻ったときに、通知の状態が更新されます。アクティビティのグラフの目盛りの0にも、ラベルが付きました。

### アップデート
remAInを終了し、アプリケーションフォルダのものを新しい版に置き換えて、開いてください。設定と履歴は、そのまま残ります。remAInは、まだAppleの署名がないため、macOSが、もう一度許可を求めることがあります(*システム設定 → プライバシーとセキュリティ → このまま開く*)。

そのほかは、1.0.0と同じです。詳しくは、[README](https://github.com/haruhito767676/remain/blob/main/README.ja.md)をご覧ください。
