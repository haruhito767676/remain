# 紹介動画 絵コンテ（たたき台）

約 80 秒、音声なし。画面の文字だけで伝える。同じ HTML の場面を、README 用の短いクリップと、サイトの動くデモにも使い回す。

## 方針

- **舞台は HTML で組む。** デスクトップ（壁紙、メニューバー、Dock、フォルダ、窓）を HTML と CSS で作り、カメラ（拡大・移動）も CSS の変形で動かす。remAIn 自身の画面は、実際のアプリのスクリーンショットを貼る。
- **時刻を指定して 1 コマずつ書き出す。** 場面は `seek(t)` で任意の時刻の絵に切り替えられるようにし、ヘッドレスの Chrome で 1 コマずつ撮って `ffmpeg` で mp4 にする。録画のカクつきが出ず、何度でも同じ結果になる。
- **大きさは 1920×1080、30fps。** 内部は 2 倍の解像度で描き、拡大しても文字が崩れないようにする。
- **文字は英語。** 「remain」の駄洒落が主役なので、画面の文字（見出し、アプリの画面）は英語にする。日本語版は、見出しの文言を差し替える形で、あとから作る。
- **ダーク（Tahoe Dark）を基本にする。** メニューバーのアイコンや、半透明のメニューが映えるため。

## 登場する窓と、エージェントの見せ分け

| エージェント | 窓 | 見分け方 |
|---|---|---|
| Antigravity | IDE の窓（左にエディタ、右にエージェントのパネル、下にステータスバー） | 左上の Apple マークの横のアプリ名が「Antigravity IDE」。Dock に本物のアイコン |
| Codex | ChatGPT アプリの窓（左にサイドバー、中央に会話、下に入力欄） | アプリ名が「ChatGPT」。サイドバーの見出しが「Codex」。Dock に本物のアイコン |
| Claude Code | ターミナルの窓 | アプリ名は「ターミナル」。窓のタイトルに `claude`、枠付きの見出しに「Claude Code」の文字を、**オレンジ**で。ロゴとキャラクターは使わない |

- 窓の中身は、こちらで作った架空の内容にする（ダミーのプロジェクト、作業ログ）。個人情報、実在の会話、バージョン番号、組織名は入れない。
- 各社の画面を複製しない。構造と雰囲気だけを寄せ、配色は近い雰囲気にとどめる。

## 小物

- **壁紙:** Tahoe Dark（`TahoeDark.heic`）。
- **メニューバー:** 左に Apple マーク、アプリ名、メニュー項目。右に、他のアイコン（検索、Wi-Fi、バッテリー、コントロールセンター、時計）を SVG で描き起こす。実際のメニューバーは撮らない。remAIn のアイコンは、状態ごとの 4 種（きらめき、カップ、砂時計、月）を、実際のアプリと同じ SF Symbols から画像にして使う。
- **Dock:** このMacにインストールされているアプリから、本物のアイコンを画像として取り出す。Finder、Safari、メール、メモ、カレンダー、システム設定、ターミナル、Google Chrome、Visual Studio Code、ChatGPT、Antigravity IDE。関係のない企業のアプリは入れない。
- **デスクトップのフォルダ:** Finder 標準のフォルダのアイコンに、`web-app`、`api-server`、`mobile-app`、`docs-site`（スクリーンショットのサンプル履歴と同じ名前）。
- **MacBook の絵:** 蓋を閉じる場面だけ使う、簡単なベクターの絵。

## 作る順序

1. 素材: 壁紙、Dock のアイコン、メニューバーのアイコン、フォルダ、窓のひな型。
2. 舞台（`stage.html`）とカメラの仕組み、1 コマずつ書き出す仕組み（`record.mjs`）。
3. 場面を 1 つずつ作る（0 → 2 → 3 → 4 → 5 → 1 → 6 → 7）。
4. 通しで確認し、README 用の短いクリップ（WebP）と、サイト用のポスターを書き出す。
