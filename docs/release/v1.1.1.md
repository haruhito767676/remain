## remAIn 1.1.1

**The `remain` command now works in Terminal.**

### What's new
- **Command Line, in Settings.** *Settings → Command Line → Install…* adds the `remain` command to Terminal, so `remain run -- <command>`, `remain status` and the rest work by name. It asks for your password once (it adds a link in `/usr/local/bin`). If you move the app, Settings shows *Needs repair* and **Repair…** fixes it. A file of your own named `remain` is never touched. *Reset Settings…* removes the link.
- The About window shows just the version, without a build number.

### Updating
Quit remAIn, replace it in Applications with the new version and open it. Your settings and history are kept. remAIn is still **not signed** by Apple, so macOS may ask you to allow it again (*System Settings → Privacy & Security → Open Anyway*).

Everything else is as in 1.1.0. Details: [README](https://github.com/haruhito767676/remain#readme)

## remAIn 1.1.1（日本語）

**ターミナルで `remain` コマンドが使えるようになりました。**

### 新しくなったこと
- **設定に「コマンドライン」を追加。** 「設定 → コマンドライン → インストール…」で、ターミナルに `remain` コマンドが加わり、`remain run -- <コマンド>` や `remain status` などを、名前だけで呼べるようになります。パスワードを一度だけ聞かれます(`/usr/local/bin` にリンクを作ります)。アプリを移動したときは、設定に「修復が必要」と出て、「修復…」で直せます。同じ名前のあなたのファイルには、触れません。「設定をリセット…」で、リンクも取り除きます。
- 「remAInについて」に、ビルド番号を出さず、バージョンだけを表示します。

### アップデート
remAInを終了し、アプリケーションフォルダのものを新しい版に置き換えて、開いてください。設定と履歴は、そのまま残ります。remAInは、まだAppleの署名がないため、macOSが、もう一度許可を求めることがあります(*システム設定 → プライバシーとセキュリティ → このまま開く*)。

そのほかは、1.1.0と同じです。詳しくは、[README](https://github.com/haruhito767676/remain/blob/main/README.ja.md)をご覧ください。
